# x6o4-tools —— 让 AI 帮你把文章送到 Kindle 和笔记里

这是一个免费开源的小工具。它配合 [RSS Cloud](https://rss-cloud.x6o4.com)（一个订阅文章的云服务）使用。

**你需要先订阅 RSS Cloud，才能使用这里的任何功能。**

## 它能帮你做三件事

1. **把没读的文章推到 Kindle。** 你对 AI 助手说一句「把未读文章推到 Kindle」。它会挑出适合长时间阅读的文章（公告、视频合集这类会自动跳过），打包成一本电子书，发到你的 Kindle。发送成功后，这些文章会自动标记为已读，下次不会重复推送。
2. **把收藏的文章推到 Kindle。** 你收藏的文章打包成电子书发到 Kindle。收藏不会消失。
3. **把收藏的文章存进笔记。** 收藏的文章变成一篇篇笔记文件，放进 [Obsidian](https://obsidian.md)（一个记笔记的软件）的文件夹。重复执行不会产生重复文件。

整个过程你只需要说一句话。做完后 AI 会告诉你：发了哪几篇、跳过了哪几篇、为什么跳过。如果你觉得某篇被跳过很可惜，说一句「把那篇也推给我」就行。

## 开始之前，请准备三样东西

1. **一个已订阅的 RSS Cloud 账号**（邮箱 + 密码）。
2. **一台 Kindle 和它的接收邮箱。** 这个邮箱在亚马逊网站上看：登录亚马逊 →「管理我的内容和设备」→「个人文档设置」→「发送至 Kindle 电子邮件地址」，长得像 `xxxx@kindle.com`。
3. **一个你自己的邮箱**（QQ 邮箱、163、Gmail 都可以）。它负责把电子书发出去。

有两个要提前知道的事：

- 亚马逊中国区已经停止个人文档服务。你要用**国际区**亚马逊账号的 `@kindle.com` 地址。
- 你的发件邮箱要先加入亚马逊的认可名单：「个人文档设置」→「认可的发件人电子邮箱列表」→ 添加你的邮箱。**不加的话，发出去的电子书会被亚马逊悄悄丢弃，而且不会有任何提示。**

## 安装（两条路，选一条）

### 路线一：让 AI 帮你装（推荐）

打开你平时用的 AI 助手（ZCode、Claude Code 等），把这个仓库的地址发给它，说：

> 帮我根据这个仓库安装并配置里面的工具和技能：https://github.com/veesong/x6o4-tools

AI 会做完所有事。只有一步会停下来等你：需要你亲自在终端里输入密码（密码不应该经过 AI，这是在保护你）。

### 路线二：自己动手装

你的电脑需要先装好 [Node.js](https://nodejs.org)（选 18 或更高版本，安装时一路点「下一步」就行）。然后打开终端（Windows 在开始菜单搜「终端」或「命令提示符」），输入：

```bash
npm install -g x6o4-tools
```

在国内如果安装很慢或失败，换成 `npm install -g x6o4-tools --registry=https://registry.npmmirror.com` 再试。

装好后命令行就能用了（输入 `x6o4` 试试）。如果你还要「AI 技能」（让 AI 一句话帮你推送），把[这个仓库](https://github.com/veesong/x6o4-tools)里的 `skills` 文件夹交给 AI 助手安装，或参考仓库说明。

## 第一次使用：登录一次，以后不用再管

在终端输入 `x6o4 login`，它会问你两个问题：

1. **邮箱**：输入你的 RSS Cloud 登录邮箱，回车。
2. **密码**：输入你的 RSS Cloud 密码。屏幕上不会显示任何字符，这是正常的，输完直接回车。

看到「✔ 已授权」就成功了。**你的密码不会被保存**；保存下来的是一串很长的字符（叫做「长期令牌」），它代表你给的授权，只存在你自己的电脑上，随时可以收回（见下面「出问题时怎么办」）。

接下来把另外两样信息填进配置（可以让 AI 帮你问、帮你填）：

- 你的 Kindle 接收邮箱（`xxxx@kindle.com`）
- 你的发件邮箱，和它的「授权码」

「授权码」是什么？邮箱厂商不允许程序直接用你的登录密码发信，而是发给你一串专用的密码，就叫授权码。去哪里拿：

| 邮箱 | 获取授权码的路径 |
|---|---|
| QQ 邮箱 | 网页版登录 → 设置 → 账号 → 开启 SMTP 服务 → 生成授权码 |
| 163 邮箱 | 设置 → POP3/SMTP/IMAP → 开启并获取授权码 |
| Gmail | 先开启两步验证，然后到「我的账号」创建应用专用密码 |
| Outlook / iCloud | 账户安全设置里的应用密码 |

**不想申请授权码，也可以改用 agent mail 发信。** agent mail 是腾讯推出的一个独立邮箱产品（和 QQ 邮箱不是同一个东西，地址在 agent.qq.com），专门给 AI 助手用。它提供一个小工具（agently-cli），在浏览器里点一次授权链接就能发信，不需要授权码。想用它的话：注册一个 agent mail 邮箱，让 AI 助手帮你装好这个小工具，再在终端运行一次 `agently-cli auth login` 完成授权，最后把配置里的 `mail_transport` 改成 `agently` 即可。注意：发件地址就是这个 agent mail 邮箱，它同样要先加入亚马逊的认可名单。

## 日常使用（对 AI 说一句话就行）

- 「把未读文章推到 Kindle」
- 「把最近一个月的收藏推到 Kindle」
- 「把收藏转成 Markdown 存进我的笔记库」

第一次用「存进笔记」时，AI 会问你笔记库在电脑上的哪个文件夹，告诉它一次，以后就记住了。

## 出问题时怎么办

| 你看到的 | 意思 | 怎么办 |
|---|---|---|
| 提示令牌无效或已吊销 | 你改过 RSS Cloud 密码，或账号状态有变化 | 再运行一次 `x6o4 login` |
| 提示权益不足 / 需要订阅 | RSS Cloud 订阅到期了 | 续订后即可继续用 |
| 邮件发出去了，Kindle 却没收到 | 发件邮箱不在亚马逊认可名单里 | 按「开始之前」第二条处理 |
| 想切断这个工具的全部权限 | —— | 先运行 `x6o4 tokens list` 看编号，再运行 `x6o4 tokens revoke 编号`；或者直接修改 RSS Cloud 密码（会立即吊销全部令牌） |

## 你的隐私

- 你的密码只在你敲键盘那一刻存在，不保存、不外传，AI 也看不到。
- 长期令牌只保存在你自己的电脑（用户目录下的 `.x6o4-tools` 文件夹）。它只能读你的文章、把文章标记已读，动不了你的密码和账号设置。
- 你的文章内容只在你自己的电脑和你自己的邮箱之间流转，不经过任何第三方。
- 想收回权限，随时可以（见上一节最后一行）。
